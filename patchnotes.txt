# Ernesh Mobile X patch notes - Tokyo quick restart 2026-11-20 (live APK 680 / data v95). Player-facing only; technical = "Game Optimization".
APP UPDATE 680
- Please UPDATE the app when the update popup shows.

DISPLAY
- New: Display Fix setting (System > General > Performance). If your screen shows a doubled, flickering or broken picture, pick another Display Fix option. Default keeps your phone's normal setting.
- Phones with a 90 Hz screen can now run at 90 FPS on High.

STABILITY
- Fixed a server crash that could happen when an idle player was disconnected.
- The game now uses less memory after you close big windows (Inventory, Point Shop, Character), so low-memory phones close less often.
- When the game has a problem, a short log is sent to us automatically so we can fix it faster.

LOGIN
- Changing your network (Wi-Fi to mobile data) no longer blocks your login. If you see "already logged in" after switching network, just try again.

ITEMS
- Fixed: 6 emoji items could not be used properly after buying them.
