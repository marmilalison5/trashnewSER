LOGIN
- New login screen with a new background and login panel.
- New Server Select and Character Select screens (Characters list + Character Info).
- New pop-up windows for every message (Yes / No, OK, input boxes).
- The phone keyboard Enter now moves to the next box / confirms.

LOADING
- New loading screens. Mining Cave has its own loading screen.

NEW HUD DESIGN
- New HP / MP / SP / EXP / CP panel, Level / Reborn display and weapon slot.
- New minimap with map name, time, your X Y position and phone battery.
- New skill buttons, attack button, joystick, Force PK button and target display.
- New chat window with tabs (All, Whisper, Party, Club, League, System).
- Names over players and monsters are bold and cleaner (guild name keeps its background).
- Top 3 ranking badge over the name of ranked players.
- New players start with a ready-made HUD layout (you can still change yours in Edit HUD).

NEW WINDOWS
- New Menu and Add Home Screen.
- New Inventory, Character, Skills, Quest, Ranking, Map, Party, Mini Party, Friends, Club, Party Finder windows.
- New Point Shop, Item Bank, Locker, Gacha, Pet, PvP, Emoticon, Codex (Character Growth) and Product windows.
- New AUTO, Macro, Equip Lock, Bag Lock and Locker Lock windows.
- New System window: General, Video, Sound and Game tabs. New Language and Performance windows.
- Window texts follow your selected language.

SOUND
- Sound effects when a window opens and when you pick a tab.
- Gacha machine sound effects.
- Volume: Menu > System > Sound > Sound Effects.

COMBAT
- Critical hits now work. Your critical chance comes from your items, buffs and skills.
- Ranking critical bonus: Top 1 +6%, Top 2 +5%, Top 3 +3%.
- Critical chance and crushing blow chance are capped at 50%.
- Critical hits and crushing blows deal x1.5 damage. Critical damage numbers are RED.
- New Critical row in the Character window.

SKILLS
- Extreme Fist can now use ALL skills.
- Skills no longer need arrows, talismans or bullets unless you use a bow, spear or gun.
- Revive skills (Fighter / Extreme) now work in events.
- Berserk and ghosting skills fixed.

NEW ITEMS
- Emoticon cards: Patotoya, Yawa, Kupal Ka Ba and oooohaha - an image with sound over your head.

MAPS AND EVENTS

- Royal Rumble: joining the event is fixed.
- Mining Cave: minimap added, crystals renamed.

FIXES
- Item Shop preview no longer closes the game.
- Item Bank fixed.
- Ranking: if the list is empty, wait one minute and open it again.

OTHERS
